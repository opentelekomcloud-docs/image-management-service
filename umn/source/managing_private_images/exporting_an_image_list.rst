Exporting an Image List
=======================

Scenarios
---------

You can export the public or private image list in the current region as an XLSX file to your local PC.

-  For public images, the file contains the image name, ID, status, OS, image type, disk capacity, boot mode, creation time, and minimum memory.
-  For private images, the file contains the image name, ID, status, OS, image type, creation time, disk capacity, image size, release status, encryption status, boot mode, and other information.

Exporting Public Image Information
----------------------------------

#. Log in to the management console.

   a. Under **Computing**, click **Image Management Service**. The IMS console is displayed.

#. On the **Public Images** tab, choose **Export** > **Export all data to an XLSX file.** above the image list.

   The system will automatically export the list of all public images in the current region to a local directory.

Exporting Private Image Information
-----------------------------------

#. Log in to the management console.

   a. Under **Computing**, click **Image Management Service**. The IMS console is displayed.

#. On the **Private Images** tab, select the target images to be exported and choose **Export** > **Export selected data to an XLSX file.** above the image list.

   The system will automatically export the list of selected private images in the current region under your account to a local directory.
