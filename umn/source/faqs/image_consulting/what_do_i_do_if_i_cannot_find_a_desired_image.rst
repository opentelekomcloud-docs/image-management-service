What Do I Do If I Cannot Find a Desired Image?
==============================================

Log in to the management console and choose **Computing** > **Image Management Service**. View OS types and versions on the **Public Images** page. If you cannot find a desired image, you have the following options:

-  Download an image file from the official OS website and then use the file to create a private image. For details, see :ref:`Creating a Windows System Disk Image from an Image File <en-us_topic_0000002214579410>` or :ref:`Creating a Linux System Disk Image from an Image File <en-us_topic_0030713190>`. The image file can be in VMDK, VHD, QCOW2, RAW, VHDX, QED, VDI, QCOW, ZVHD2, or ZVHD format.
-  If the image belongs to another account, ask the tenant to share it with you. For details about image sharing, see :ref:`Sharing Specified Images <en-us_topic_0032042419>`.
