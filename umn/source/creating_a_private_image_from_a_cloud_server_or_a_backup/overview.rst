Overview
========

A private image contains an OS or service data, preinstalled public applications, and a user's personal applications. Private images are only available to the users who created them.

IMS provides multiple methods for creating private images.

.. table:: **Table 1** Creating a private image

   +-----------------------------------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------+
   | Method                                              | Description                                                                                                                                                                                                                                                                                                | Helpful Link                                                                                    |
   +=====================================================+============================================================================================================================================================================================================================================================================================================+=================================================================================================+
   | Creating a private image from an ECS                | If you have created an ECS on the cloud platform and customized it based on your service requirements (such as installing software or deploying application environments), you can use the ECS to create a private image.                                                                                  | -  :ref:`Creating a Windows System Disk Image from a Cloud Server <en-us_topic_0030713149>`     |
   |                                                     |                                                                                                                                                                                                                                                                                                            | -  :ref:`Creating a Linux System Disk Image from a Cloud Server <en-us_topic_0030713180>`       |
   |                                                     | -  System disk image: contains an OS and application software from the system disk.                                                                                                                                                                                                                        | -  :ref:`Creating a Data Disk Image from an ECS <en-us_topic_0102644450>`                       |
   |                                                     | -  Data disk image: contains service data from data disks.                                                                                                                                                                                                                                                 | -  :ref:`Creating a Full-ECS Image from an ECS <en-us_topic_0116125142>`                        |
   |                                                     | -  Full-ECS image: contains data of an entire ECS, that is, the OS and application software from the system disk and service data from data disks.                                                                                                                                                         |                                                                                                 |
