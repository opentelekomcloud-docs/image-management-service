Creating Image Metadata (Native OpenStack API)
==============================================

Function
--------

This API is used to create image metadata.

After the API is successfully invoked, the image metadata is created, but the image file does not exist yet.

URI
---

POST /v2/images

Request
-------

-  Request parameters

   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | Parameter        | Mandatory       | Type             | Description                                                                                                                                                                                                                                                                                                                    |
   +==================+=================+==================+================================================================================================================================================================================================================================================================================================================================+
   | \__os_version    | No              | String           | Image OS version. For the value range, see :ref:`Values of Related Parameters <en-us_topic_0031617666>`.                                                                                                                                                                                                                       |
   |                  |                 |                  |                                                                                                                                                                                                                                                                                                                                |
   |                  |                 |                  | If this parameter is not specified, the value **Other Linux(64 bit)** will be used. In that case, the ECS creation using this image may fail, and the ECS created using this image may fail to run properly.                                                                                                                   |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | visibility       | No              | String           | Whether an image is visible to other tenants.                                                                                                                                                                                                                                                                                  |
   |                  |                 |                  |                                                                                                                                                                                                                                                                                                                                |
   |                  |                 |                  | The default value is **private**. When creating image metadata, the value of **visibility** can be set to **private** only.                                                                                                                                                                                                    |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | name             | No              | String           | Image name. If this parameter is not specified, its value is empty by default. In that case, ECS creation using this image will fail. The name contains 1 to 255 characters. For details about **name**, see :ref:`Image Attributes <en-us_topic_0020091562__section61598810155254>`. This parameter is left blank by default. |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | protected        | No              | Boolean          | Whether an image is protected. A protected image cannot be deleted. The default value is **false**.                                                                                                                                                                                                                            |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | container_format | No              | String           | Container format.                                                                                                                                                                                                                                                                                                              |
   |                  |                 |                  |                                                                                                                                                                                                                                                                                                                                |
   |                  |                 |                  | The default value is **bare**.                                                                                                                                                                                                                                                                                                 |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | disk_format      | No              | String           | Image format. The value can be **zvhd2**, **vhd**, **raw**, or **qcow2**. The default value is **zvhd2**.                                                                                                                                                                                                                      |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | tags             | No              | Array of strings | Image tags. The length is limited to 1 to 255 characters. By default, an image has no tags.                                                                                                                                                                                                                                    |
   |                  |                 |                  |                                                                                                                                                                                                                                                                                                                                |
   |                  |                 |                  | .. note::                                                                                                                                                                                                                                                                                                                      |
   |                  |                 |                  |                                                                                                                                                                                                                                                                                                                                |
   |                  |                 |                  |    The tag is a key-value pair. Example:                                                                                                                                                                                                                                                                                       |
   |                  |                 |                  |                                                                                                                                                                                                                                                                                                                                |
   |                  |                 |                  |    .. code-block::                                                                                                                                                                                                                                                                                                             |
   |                  |                 |                  |                                                                                                                                                                                                                                                                                                                                |
   |                  |                 |                  |       "tagkey=tagvalue"                                                                                                                                                                                                                                                                                                        |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | min_ram          | No              | Integer          | Minimum memory (MB) required for running an image. The parameter value depends on ECS specifications. The default value is **0**.                                                                                                                                                                                              |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | min_disk         | No              | Integer          | Minimum disk space (GB) required for running an image. The value ranges from 1 GB to 1,024 GB.                                                                                                                                                                                                                                 |
   |                  |                 |                  |                                                                                                                                                                                                                                                                                                                                |
   |                  |                 |                  | The value of this parameter must be greater than the image system disk capacity. Otherwise, the ECS creation may fail.                                                                                                                                                                                                         |
   +------------------+-----------------+------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

Example Request
---------------

.. code-block:: text

   POST https://{Endpoint}/v2/images
   {
       "__os_version": "Ubuntu 14.04 server 64bit",
       "container_format": "bare",
       "disk_format": "vhd",
       "min_disk": 100,
       "min_ram": 1024,
       "name": "test",
       "tags": [
           "test=testvalue",
           "image=imagevalue"
       ],
       "visibility": "private",
       "protected": false
   }

Response

The value is **private**.                                                                                                                                                                                                                     |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

   | protected             | Boolean               | Whether an image is protected. A protected image cannot be deleted.    +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | container_format      | String                | Container format.                                                                                                                                                                                                                                                                           |
   |                       |                       |                                                                                                                                                                                                                                                                                             |
   |                       |                       | The value is **bare**.                                                                                                                                                                                                                                                                      |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | disk_format           | String                | Image format. The value can be **zvhd2**, **vhd**, **raw**, or **qcow2**. The default value is **zvhd2**.                                                                                                                                                                                   |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | tags                  | Array of strings      | Image tags. The length is limited to 1 to 255 characters.                                                                                                                                                                                                                                   |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

The value is generally set to **0**.                                                                                                                                        |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

Otherwise, the ECS creation will fail. The value ranges from 1 GB to 1,024 GB.                                                                                        |

   | status                | String                | Image status. The value can be one of the following:                                                                                                                                                                                                                                        |

   |                       |                       | -  **queued**: indicates that the image metadata has already been created, and it is ready for the image file to upload.                                                                                                                                                                    |
   |                       |                       | -  **saving**: indicates that the image file is being uploaded to the backend storage.                                                                                                                                                                                                      |
   |                       |                       | -  **deleted**: indicates that the image has been deleted.                                                                                                                                                                                                                                  |
   |                       |                       | -  **killed**: indicates that an error occurs on the image uploading.                                                                                                                                                                                                                       |
   |                       |                       | -  **active**: indicates that the image is available for use.                                                                                                                                                                                                                               |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | created_at            | String                | Image creation time. The value is in UTC format.                                                                                                                                                                                                                                            |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

The value is in UTC format.                                                                                                                                                                                                                                              |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | self                  | String                | Image URL.                                                                                                                                                                                                                                                                                  |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | id                    | String                | Image ID. After the image creation API is called, the image ID must be saved. The image ID is used to invoke the image uploading API and upload the image.                                                                                                                                  |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | file                  | String                | URL for uploading and downloading an image file.                                                                                                                                                                                                                                            |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | schema                | String                | Schema URL.                                                                                                                                                                                                                                                                                 |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

Only UDS is supported currently.                                                                                                                                                                                                                                |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | \__image_size         | String                | Image size. The unit is byte.                                                                                                                                                                                                                                                               |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | \__isregistered       | String                | Whether an image is registered. Only registered images can be queried on the portal. The value is **true**.                                                                                                                                                                                 |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | \__os_version         | String                | Image OS version. For the value range, see :ref:`Values of Related Parameters <en-us_topic_0031617666>`.                                                                                                                                                                                    |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | \__os_type            | String                | Image OS type. The value of this parameter depends on that of **\__os_version**. The value can be **Windows**, **Linux**, or **other**.                                                                                                                                                     |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | \__platform           | String                | OS platform supported by an image. The value of this parameter depends on that of **\__os_version**.                                                                                                                                                                                        |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | \__os_bit             | String                | OS bitness. The value of this parameter depends on that of **\__os_version**. The value can be **32** or **64**.                                                                                                                                                                            |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | \__imagetype          | String                | Image type. **private** indicates a private image.                                                                                                                                                                                                                                          |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | virtual_env_type      | String                | Platform type.                                                                                                                                                                                                                                                                              |
   |                       |                       |                                                                                                                                                                                                                                                                                             |
   |                       |                       | Environment where an image is used. The value can be **FusionCompute**, **Ironic**, **DataImage**, or **IsoImage**.                                                                                                                                                                         |
   |                       |                       |                                                                                                                                                                                                                                                                                             |
   |                       |                       | -  For an ECS image, the value is **FusionCompute**.                                                                                                                                                                                                                                        |
   |                       |                       | -  For an ECS data disk image, the value is **DataImage**.                                                                                                                                                                                                                                  |
   |                       |                       | -  For a BMS image, the value is **Ironic**.                                                                                                                                                                                                                                                |
   |                       |                       | -  For an ISO image, the value is **IsoImage**.                                                                                                                                                                                                                                             |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | owner                 | String                | ID of the project that an image belongs to.                                                                                                                                                                                                                                                 |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | \__root_origin        | String                | Origin of an image. The value is **file**.                                                                                                                                                                                                                                                  |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | checksum              | String                | MD5 value of an image file.                                                                                                                                                                                                                                                                 |
   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

   +-----------------------+-----------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | virtual_size          | Integer               | Virtual size of an image.    | properties            | Properties object     | A collection of image attributes. It does not represent a specific image attribute.                                                                                                                                                                                                         |
